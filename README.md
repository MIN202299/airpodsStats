# AirPods 佩戴统计（耳机统计）

一个 SwiftUI iOS 应用，读取「健康」App 里的耳机历史，统计 AirPods 的佩戴时长。界面仿照参考截图：蓝黑网格背景、圆角卡片、白色渐变柱形图。

## 功能

**首次启动**：说明数据来源和隐私，再选“连接健康 App”或“先看看示例数据”。

**统计页**
- 个人纪录：单日佩戴最长、单次佩戴最长（含起止时间）、连续记录最长（天数 + 日期范围）、单月佩戴最长。轻点可跳到对应的那一天或那个月
- 最常戴耳机：设备名称 + 累计佩戴时长，轻点进入设备详情
- 周 / 月 / 年 / 总共 切换，左右箭头切换周期（点标题回到当前周期），切换栏滚动时吸顶
- 累计佩戴时长：总时长、和上一周期对比、柱形图。轻点柱形查看明细，再点“查看”逐级下钻：总共 → 年 → 月 → 当天
- 周期概览：有记录日平均、有记录天数 / 周期总天数、周期最长单日、佩戴次数
- 右上角筛选：全部耳机 / 仅 AirPods / 任选几副；筛选生效时页面顶部有提示条，可一键清除

**今天页**（可以翻看任意一天）
- 左右箭头或左右滑动切换日期，“回到今天”一键返回；从统计页、纪录卡片、设备详情跳过来时直接显示那一天
- 当日佩戴时长（和前一天对比）、24 小时分布、佩戴次数 / 最长一次 / 本周累计 / 近 7 日平均
- 近 7 天柱形图（点柱形后可“查看这一天”）、当日每次佩戴的记录（轻点跳到对应耳机）

**设备页**（深紫夜空风格）
- 右上角切换时间范围：近7天 / 近30天 / 本周 / 本月 / 全部；左上角齿轮进入设置
- 粒子球显示该范围的总佩戴时长（页面不可见或开启“减弱动态效果”时暂停动画）
- 可左右滑动的玻璃质感设备卡片，底部分页圆点；轻点进入详情；长按可查看详情、全部记录、编辑 / 合并 / 隐藏
- 下拉刷新

**设备详情页**：所选周期时长和占比；厂商与型号；累计聆听时长；累计次数、平均每次、最长一次、平均音量 dB(A)；近 30 天趋势（可跳到某一天）；最近 5 次佩戴 + 查看全部记录（按天分组）

**编辑耳机**：重命名；合并到另一副耳机（AirPods 改名或系统更新后可能被识别成两副），可随时拆分；在统计中隐藏

**设置**：数据来源、会话合并间隔、重新读取、在健康 App 中管理权限；已隐藏 / 已合并耳机的恢复与拆分、一键重置；导出 CSV（可用 Excel 打开）；清除本地缓存；统计方式说明；版本号

**可靠性**
- 读取和统计都在后台线程完成，界面不卡顿；启动时先显示本地缓存
- 同一时间只进行一次读取，启动、回到前台、下拉刷新同时触发时会合并成一次；回到前台 60 秒内不重复读取
- App 打开期间健康 App 写入新数据会自动刷新
- 读取失败时保留上次的数据并提示重试；没有权限或没有数据时有引导；筛选后为空时可一键清除筛选
- 数值支持旁白（VoiceOver），例如“13 小时 52 分钟”
- 含隐私清单（PrivacyInfo.xcprivacy），不收集、不上传任何数据

## 数据从哪里来

iOS 不开放 AirPods 的入耳检测记录。本应用使用 HealthKit 的 **耳机音频级别**（`HKQuantityType(.headphoneAudioExposure)`）样本：耳机播放音频时，系统会持续写入带设备信息（如 “AirPods Pro”）的样本，并长期保存历史。处理流程：

1. 读取全部样本，按设备分组（名称 + 型号 + 本地标识）
2. 同一设备相邻样本间隔 ≤ N 分钟（默认 5，可调）的合并成一次“佩戴会话”
3. 跨午夜的会话按天拆开，再计算日 / 月 / 年统计和各项纪录

所以统计的是“戴着耳机播放音频的时长”：只开降噪、不放音频的时段不会被记录，也就是界面上写的 **“无记录不等于未佩戴”**。所有计算都在本机完成。

## 运行

需要 Xcode 16 或更高版本，系统要求 iOS 17 及以上。

1. 打开 `AirPodsStats.xcodeproj`
2. 在 *Signing & Capabilities* 里选择你的 Team，并把 Bundle Identifier 改成你自己的（默认是 `com.example.airpodsstats`）
3. 运行到真机，首次启动时允许读取“耳机音频级别”
4. 模拟器里没有耳机数据，可以在 设备 → 数据来源 切到“示例数据”预览界面

运行单元测试：在 Xcode 中按 ⌘U，覆盖会话合并、跨天拆分、各项纪录、周期统计、设备合并 / 隐藏 / 筛选、时长格式和 CSV 导出。

如果工程打不开，可以用 XcodeGen 重新生成：`brew install xcodegen && xcodegen generate`。

如果读不到数据：检查 健康 → 共享 → App → 耳机统计 是否打开了“耳机音频级别”，以及 设置 → 健康 → 耳机音频级别 是否开启。

## 代码结构

```
AirPodsStats/
  App/          入口（引导页 / TabView）
  Models/       RawSample / WearSession / HeadphoneDevice / PeriodKind / DevicePeriod
  Analytics/    SessionBuilder（样本 → 会话）、StatsEngine（全部统计，纯计算）、Formatting
  Services/     UsageStore（数据与设置）、AppRouter（跨页导航）、HealthKitService、
                DemoDataGenerator、SessionCache、SessionExport（CSV）
  Views/        Components、Stats、Today、Devices、OnboardingView
  PrivacyInfo.xcprivacy
AirPodsStatsTests/   单元测试
Config/AirPodsStats.entitlements   HealthKit 权限
```

`StatsEngine`、`SessionBuilder` 和 `UsageStore.process` 都是纯函数，不依赖界面和 HealthKit，单元测试直接覆盖它们。
